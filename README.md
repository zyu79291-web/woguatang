# 窝瓜汤

个人 PTE WFD 整句听写、SST 记忆复述与 WE 模板打字练习站。仓库设为 Private，仅供自己保存和维护。

## 功能

- SST 听力：60 道题，每题直接展示 6 个中英关键点；原资料的 395 句完整保留，7 句的题将相关两句归为一点。支持搜索、上一题/下一题和独立笔记，沿用本机备份。已接入 59 道本地录音：57 道猩际录音、1 道影子三千标注的原音频，以及 1 道 PTEBank 参考录音（页面明确标注“近似音频”）。全部检查完整解码、有效音量和文件哈希；支持原生播放、变速及循环，切换题目会停止播放。女性体脂实验尚未找到匹配录音。通过 `/?module=sst` 进入。

- WE 作文与论点：导入 37 篇原文，逐篇显示中英文总论点、两个分论点、解释、例子和完整作文；按同类论点反查相关作文，支持题号/中英文/总论点搜索，并保留上次浏览位置

- WE 模板打字：按四段或全篇练习固定英文，中文填空位置作为提示；支持对照练习和默打、实时用时/WPM/准确率、各段独立草稿和最近成绩，沿用本机备份

- WFD 试词练习分：每次提交显示正确词数/答案词数，按拼写和重复次数匹配，忽略顺序，多写备选词不扣练习分；开始新一轮时隐藏上轮词分和总词数；词分满分视为写对，一遍过仍要求只听一遍、不看答案、首次提交满分（这是本地练习规则，并非官方评分承诺）
- WFD 提交前只显示自己输入的文字，不显示逐词横线、预设空位或答案词长；提交后保留错词检查与定位修改
- 原版整句音频与当前题循环播放（Alt/Option + L 开关循环）
- 点击循环开关后焦点回到输入区，可直接打字
- 清空重做会结束循环，并从头播放一遍当前题；仍属于当前轮，不增加轮次或累计轮数
- 可开关的一遍过：每轮只听一遍、不看答案、首次提交全对即可通关；本轮不满足条件时先继续修改，整句全对后按 Enter 重开一轮，隐藏答案并重播一次
- Enter 提交后同时批改并显示中英文答案，上方英文答案用橙色标出漏写或写错的正确单词；高亮与试词词分使用相同的次数匹配规则；开始打字时自动隐藏。自动重开的一轮继续隐藏答案和上轮词分；提交前看过答案的轮次仍不计独立通关
- 每道题累计记录练习轮数，列表和听写窗均显示；重听、修改和刷新不重复计数，旧版本明确保存的轮数作为已知下限保留
- 按 Enter 检查后选中首个错词，输入可替换旧词；整句始终自由编辑，空格正常分词，可追加任意数量的备选词、粘贴或删改已写内容，显式按 Enter 后才提交，不自动结束输入
- 随机练习开关与再次打乱：当前题和输入保留，其余题目随机排序；上一题/下一题遵循同一顺序，刷新后继续，关闭后恢复原题库顺序
- 题目列表和听写窗均可点星标收藏，支持只看收藏、收藏题随机练习，并自动保存和备份；题库更新后仍可练习已收藏的归档题
- 搜索、练习状态、错词本和续练
- 每日有效时长、完成题数及最近 7 天记录
- 浏览器保存与本机自动备份、导入和导出
- 每天首次运行时增量同步题库，完整取得新题原版录音后更新

## 专注模式（可选）

Chrome 内只允许窝瓜汤、ChatGPT 和 PTE 学姐，并由本机菜单栏组件将其他软件切回 Chrome。可随时结束，默认关闭；不会关掉其他软件和标签页。首次安装见 [focus/README.md](focus/README.md)。

## 本机运行

需要 Python 3 和系统 curl，无需安装第三方 Python 包。

```sh
python3 tools/service.py
```

Mac 首次安装或修复长期运行时，在系统终端运行 `zsh tools/start_service.sh`，由 macOS 管理登录启动和停止后的重启。启动器会确认端口属于该后台任务，未注册成功时会明确报错，不把临时恢复当作修复完成。

打开 http://localhost:8765/ 。服务只监听本机。离线导出位于 exports/，可通过 http://localhost:8765/offline 打开。

```sh
python3 tools/build_offline.py
```

## 数据与访问范围

练习记录、备份、运行日志、临时媒体票据和本机安装信息不会提交到仓库。原站进度导入文件已替换为空模板，本机现有记录不受影响。需要迁移进度时，在练习站的“练习记录”里导出 JSON，并在新浏览器中导入。

GitHub 私有仓库用于保存源码和网站资源；本仓库没有启用 GitHub Pages 或公开网站部署。私有仓库本身不等同于带登录保护的在线网站。
