# 窝瓜汤

个人 PTE WFD 整句听写练习站。仓库设为 Private，仅供自己保存和维护。

## 功能

- 原版整句音频与当前题循环播放（Alt/Option + L 开关循环）
- 点击循环开关后焦点回到输入区，可直接打字
- 清空重做会结束循环，并从头播放一遍当前题
- 可开关的惩罚模式：每轮只听一遍、不看答案、首次提交全对即可通关；重听、循环、看答案或首次写错后，须重开一轮独立听写
- 中英文答案同步显示或隐藏
- 搜索、练习状态、错词本和续练
- 每日有效时长、完成题数及最近 7 天记录
- 浏览器保存与本机自动备份、导入和导出
- 每天首次运行时增量同步题库，完整取得新题原版录音后更新

## 专注模式（可选）

Chrome 内只允许窝瓜汤、ChatGPT 和 PTE 学姐，并由本机菜单栏组件将其他软件切回 Chrome。可随时结束，默认关闭；不会关掉其他软件和标签页。首次安装见 [focus/README.md](focus/README.md)。

## 本机运行

需要 Python 3 和系统 curl，无需安装第三方 Python 包。

```sh
python3 tools/service.py
```

Mac 首次安装或修复长期运行时，在系统终端运行 `zsh tools/start_service.sh`，由 macOS 管理登录启动和停止后的重启。启动器会确认端口属于该后台任务，未注册成功时会明确报错，不把临时恢复当作修复完成。

打开 http://localhost:8765/ 。服务只监听本机。离线导出位于 exports/，可通过 http://localhost:8765/offline 打开。

```sh
python3 tools/build_offline.py
```

## 数据与访问范围

练习记录、备份、运行日志、临时媒体票据和本机安装信息不会提交到仓库。原站进度导入文件已替换为空模板，本机现有记录不受影响。需要迁移进度时，在练习站的“练习记录”里导出 JSON，并在新浏览器中导入。

GitHub 私有仓库用于保存源码和网站资源；本仓库没有启用 GitHub Pages 或公开网站部署。私有仓库本身不等同于带登录保护的在线网站。
