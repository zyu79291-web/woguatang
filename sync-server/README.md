# 窝瓜汤加密同步接口

网页继续由 GitHub Pages 提供，接口由 Cloudflare Workers / Sites 与 D1 提供。此目录保留应用接口、数据库结构与协议测试源码；不包含部署凭据或用户数据。实际 Sites 项目独立维护，迁移由平台部署流程应用。

- 设备生成 192 位随机配对密钥，校验码可检查复制错误。
- 浏览器派生彼此独立的账号 ID、接口授权和 AES-GCM 加密密钥；加密密钥不发送到服务器。
- 服务端只存授权摘要、加密进度、修订号和一份上次密文。
- 按修订号原子写入；旧修订返回 409，由客户端重新获取并合并。
- CORS 限定窝瓜汤来源，缺少授权不能读取进度；请求体有容量限制。
- 前端按题合并状态和草稿，以设备增量合并练习轮数、时长和提交次数。不同题目的草稿同时保留；同一道题取较新的修改，并在设备保留合并前备份。
- `node tests-api.mjs` 针对本地接口执行加密往返、权限隔离、并发写入和请求限制测试。可用 `SYNC_TEST_URL` 指定独立测试服务；只创建随机测试账号。

首次配对：有旧进度的电脑开启云同步，复制配对码，在 iPad 连接并合并。之后约每 15 秒及切回页面时同步；有远端变化时会在停止输入和音频后接续，以免打断当前练习。离线时继续本机保存。

配对码是进度的访问和解密凭据，切勿放进公共源码或公开链接。清除所有设备的配对码后，服务器无法恢复解密密钥。合并前备份可从云同步对话框导出，再用原“练习记录”导入恢复。
